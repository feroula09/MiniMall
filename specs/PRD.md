# Mini Mall 產品需求文件（PRD）

> 版本：v1.0 ・ 日期：2026-10-25 ・ 技術細節見 [SPEC.md](./SPEC.md)

## 1. 背景與目標

Mini Mall 是一個微型電商網站，作為練習與作品集專案，**只在本機執行**，不考慮線上部署。

目標：
- 完整走通電商核心流程：瀏覽商品 → 加入購物車 → 下單 → 模擬付款 → 出貨 → 確認收貨
- 提供後台，讓管理員維護商品、分類與訂單
- 程式碼結構清楚，按功能拆分模組，方便閱讀與擴充

## 2. 使用者角色

| 角色 | 說明 | 權限 |
|---|---|---|
| 訪客 | 未登入 | 瀏覽商品列表、搜尋、分類篩選、商品詳情；註冊、登入 |
| 註冊使用者 | `role = USER` | 訪客全部權限 + 購物車、結帳、模擬付款、查看與管理自己的訂單 |
| 管理員 | `role = ADMIN` | 註冊使用者全部權限 + 進入後台管理商品、分類、訂單 |

管理員帳號由 seed 資料建立，不提供前台註冊成管理員的途徑。

## 3. 範圍

### 3.1 In Scope
1. 商品瀏覽：列表、詳情、搜尋、分類篩選、排序、分頁
2. 帳號：註冊、登入、登出
3. 購物車：加入、修改數量、移除
4. 訂單：結帳下單、模擬付款、我的訂單（查看、取消、確認收貨）
5. 後台：概覽、商品 CRUD（含圖片上傳、上下架）、分類 CRUD、訂單管理（出貨、取消）

### 3.2 Out of Scope
- 真實金流（只做模擬付款）
- 優惠券、促銷、運費計算
- 商品評價、收藏
- 地址簿（每次結帳手動填寫收件資訊）
- 電子郵件驗證、忘記密碼
- 多規格 SKU（顏色、尺寸等）
- 線上部署、多語系

## 4. 功能需求

每個功能對應一個獨立模組與一次 commit（見第 7 節里程碑）。

### F2 商品列表 / 搜尋 / 分類篩選
**使用者故事**：作為訪客，我想按關鍵字和分類找到商品，並按價格或上架時間排序。

驗收標準：
- 首頁顯示上架中（`isActive = true`）的商品卡片：圖片、名稱、價格
- 可輸入關鍵字，比對商品名稱與描述
- 可選擇分類篩選；可與關鍵字同時使用
- 排序：最新（預設）、價格由低到高、價格由高到低
- 每頁 12 筆，有分頁元件
- 篩選條件反映在網址上，重新整理或分享連結結果相同
- 沒有結果時顯示空狀態提示

### F3 商品詳情
**使用者故事**：作為訪客，我想看商品完整資訊並加入購物車。

驗收標準：
- 顯示圖片、名稱、分類、價格、庫存、描述
- 可選擇數量（1 ～ 庫存上限）
- 點「加入購物車」：已登入則加入並提示成功；未登入則導向登入頁，登入後回到原商品頁
- 庫存為 0 時按鈕停用並顯示「已售完」
- 商品不存在或已下架時顯示 404

### F4 註冊 / 登入 / 登出
**使用者故事**：作為訪客，我想註冊帳號並登入，才能購物。

驗收標準：
- 註冊欄位：名稱、Email、密碼（至少 8 碼）、確認密碼
- Email 已被註冊時顯示錯誤
- 登入失敗統一顯示「Email 或密碼錯誤」，不透露是哪一項錯
- 登入狀態保留 7 天
- 頁首顯示目前使用者名稱與登出按鈕；管理員額外顯示「後台」入口
- 未登入存取購物車、結帳、訂單、後台頁面時，導向登入頁並在登入後回到原頁
- 一般使用者存取後台時導回首頁

### F5 購物車
**使用者故事**：作為使用者，我想把多件商品放進購物車，調整數量後一起結帳。

驗收標準：
- 同一商品重複加入時累加數量，總數不超過庫存
- 購物車頁可修改數量、移除單項
- 顯示每項小計與總計
- 頁首購物車圖示顯示商品件數，操作後即時更新
- 商品已下架或庫存不足時，該項標示警告，且無法結帳
- 購物車為空時顯示空狀態與「去逛逛」連結

### F6 結帳下單 + 模擬付款
**使用者故事**：作為使用者，我想填寫收件資訊下單並付款。

驗收標準：
- 結帳頁顯示購物車明細與總計，並填寫收件人、電話、地址
- 送出時重新檢查庫存與上架狀態；任何一項不符則整筆訂單不成立並提示原因
- 下單成功：扣減庫存、清空購物車、建立訂單（狀態「待付款」），導向付款頁
- 訂單保存當時的商品名稱、圖片、單價快照，之後商品改價或刪除不影響歷史訂單
- 付款頁顯示訂單編號與金額，按「確認付款」後狀態變為「已付款」
- 並發下單時不會超賣

### F7 我的訂單
**使用者故事**：作為使用者，我想查看訂單狀態並在適當時機取消或確認收貨。

驗收標準：
- 訂單列表依狀態分頁籤：全部、待付款、已付款、已出貨、已完成、已取消
- 訂單詳情：商品明細、金額、收件資訊、狀態時間軸
- 「待付款」可去付款或取消；「已付款」可取消；「已出貨」可確認收貨
- 取消訂單後庫存回補
- 只能看到與操作自己的訂單

### F8 後台概覽
驗收標準：
- 後台有側邊選單：概覽、商品、分類、訂單
- 概覽顯示：商品總數、訂單總數、待出貨訂單數、累計已付款金額

### F9 後台分類管理
驗收標準：
- 新增、編輯、刪除分類；欄位：名稱、slug、排序值
- 名稱與 slug 不可重複
- 分類底下仍有商品時禁止刪除並提示

### F10 後台商品管理
驗收標準：
- 商品列表：搜尋名稱、依分類與上下架狀態篩選、分頁
- 新增 / 編輯欄位：名稱、描述、價格、庫存、分類、圖片、是否上架
- 圖片上傳只接受 jpg / png / webp，大小上限 2MB；上傳後立即預覽
- 可直接在列表切換上下架
- 刪除商品時從所有購物車移除該商品；已成立訂單的快照保留

### F11 後台訂單管理
驗收標準：
- 訂單列表：依狀態篩選、依訂單編號搜尋、分頁
- 訂單詳情：買家、明細、收件資訊、狀態時間軸
- 「已付款」訂單可出貨；「待付款」與「已付款」訂單可取消（回補庫存）
- 管理員出貨後，使用者端訂單狀態同步更新

## 5. 訂單生命週期

```
待付款 ──付款──▶ 已付款 ──出貨──▶ 已出貨 ──確認收貨──▶ 已完成
  │                │
  └──取消──┐  ┌──取消──┘
           ▼  ▼
          已取消（回補庫存）
```

| 狀態 | 說明 | 可執行動作 |
|---|---|---|
| 待付款 | 剛下單，庫存已預扣 | 使用者：付款、取消；管理員：取消 |
| 已付款 | 模擬付款完成 | 使用者：取消；管理員：出貨、取消 |
| 已出貨 | 管理員已出貨 | 使用者：確認收貨 |
| 已完成 | 使用者確認收貨 | 無 |
| 已取消 | 已取消，庫存已回補 | 無 |

## 6. 非功能需求

- **金額精度**：所有金額以「分」為單位的整數儲存與計算，只在顯示時格式化
- **防超賣**：下單時在同一個資料庫交易內以條件扣減庫存
- **權限**：所有寫入操作都在伺服器端驗證登入狀態、角色與資料擁有權，不只依賴頁面跳轉
- **安全**：密碼以 bcrypt 雜湊；session 存在 httpOnly cookie；上傳檔名由伺服器產生
- **介面**：繁體中文；支援手機與桌面版面
- **可維護性**：程式碼按功能拆分模組，路由層保持精簡

## 7. 里程碑

每個項目完成後執行自檢與 code review，通過後 commit，再進行下一項。

| # | 項目 | 驗收重點 |
|---|---|---|
| 1 | 產出 PRD / SPEC 文件 | 本文件與 SPEC.md |
| 2 | 產生 CLAUDE.md 與 `.claude/settings.json` | 開發規範與權限設定 |
| F1 | 專案腳手架 | `npm run dev` 可啟動；資料庫 migrate 與 seed 成功 |
| F2 | 商品列表 / 搜尋 / 篩選 | 搜尋、分類、排序、分頁可組合使用 |
| F3 | 商品詳情 | 詳情顯示正確、404 處理 |
| F4 | 註冊登入 | 註冊 → 登出 → 登入；未登入被導向；權限擋住後台 |
| F5 | 購物車 | 加入、改數量、移除、件數角標 |
| F6 | 結帳 + 模擬付款 | 扣庫存、清購物車、付款狀態變更、超庫存下單失敗 |
| F7 | 我的訂單 | 取消回補庫存、確認收貨 |
| F8 | 後台概覽 | 統計數字正確；非管理員無法存取 |
| F9 | 後台分類 | CRUD；有商品的分類無法刪除 |
| F10 | 後台商品 | CRUD、圖片上傳在 `next start` 下可正常顯示 |
| F11 | 後台訂單 | 出貨、取消；使用者端狀態同步 |
